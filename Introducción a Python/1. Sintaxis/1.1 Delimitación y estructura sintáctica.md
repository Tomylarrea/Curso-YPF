La principal diferencia en la sintaxis en Python con lenguajes de bajo nivel tales como C o C++, es que no se utiliza punto y coma `;` al final de cada línea. Asimismo, la indentación cumple una función sintáctica: determina la estructura jerárquica del programa:

**Ejemplo:**

```python
x = 3

if x > 0:
    print('Número positivo')
else:
    print('Número no positivo')
```
