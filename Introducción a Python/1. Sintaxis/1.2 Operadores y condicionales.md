### Operadores

##### Aritméticos

| Nombre | Operador |
| :--- | :---: |
| Suma | `+` |
| Resta | `-` |
| Multiplicación | `*` |
| División | `/` |
| Módulo | `%` |
| Potencia | `**` |
| División entera | `//` |

| Nombre            | Operador |

### Sintaxis de condicionales

**Condicional
```python
if <expresión>:
  <cuerpo>
```

**Ejecución alternativa**
```python
if <expresión>:
  <cuerpo1>
else:
  <cuerpo2>
```

**Condicionales encadenados**
```python
if x < y:
  print('x es menor que y')
elif x > y:
  print('x es mayor que y')
else:
  print('x e y son iguales')
```
