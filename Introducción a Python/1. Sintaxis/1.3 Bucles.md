
**Bucle** `for`: 
```python
x = 0
for i in range(1,5):
	x = x + 1 
```
```Consola
Salida:
1
2
3
4
```

Python permite recorrer elementos en una [[2.2 Listas|lista]] o string con este tipo de ciclo:
```python
lista = [1, 42, 3j, 'Hello']
for elem in lista:
	print(elem)
```
``` Consola
Salida:
1
42
3j
Hello
```

**Bucle** `while`
```python
n = 5
while n > 0:
    print(n)
    n = n - 1
    if n == 0:
        print('¡Despegue!')
```
```Consola
Salida:
5
4
3
2
1
¡Despegue!
```
