
**Importación de módulos**
Los módulos contienen colecciones de funciones asociadas (ej. `math` para funciones matemáticas).
```python
import <nombre_módulo> 
```
*Ejemplo:* 
```python
import math
```

O, si se desea asociarle otro nombre al mismo:
```python
import <nombre_módulo> as <nombre_personalizado> 
```
*Ejemplo:* 
```python
import numpy as np
```
---
**Invocación mediante notación de punto**
```python
<nombre_módulo>.<nombre_función>(<argumento>)
```
*Ejemplo:* 
```python
math.sin(radianes)
```
---
**Composición**
Se pueden encadenar expresiones y llamadas a [[1.4 Funciones|funciones]].
```python
math.exp(math.log(x+1))
```
