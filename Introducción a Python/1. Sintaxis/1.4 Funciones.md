### Funciones

Las funciones permiten encapsular código en bloques reutilizables. Toma argumentos y devuelve un resultado (valor de retorno).

**Invocación de una función básica**
```python
<nombre_función>(<argumento>)
```

**Definición de una función nueva**
Se especifica con la palabra reservada `def`.
```python
def <nombre_función>(<parametros_separados_por_coma>):
  <cuerpo_de_la_función>
  return <valor_a_devolver>
```
*Ejemplo sin argumentos:*
```python
def hola_personas_dateras():
  return "Hola personas Dateras! Estoy programando en Python."
```
*Ejemplo con argumentos:*
```python
def suma(a, b):
  return(a + b)
```

### Módulos y composición

**Importación de módulos**
Los módulos contienen colecciones de funciones asociadas (ej. `math` para funciones matemáticas).
```python
import <nombre_módulo>
```
*Ejemplo:* `import math`

**Invocación mediante notación de punto**
```python
<nombre_módulo>.<nombre_función>(<argumento>)
```
*Ejemplo:* `math.sin(radianes)`

**Composición**
Se pueden encadenar expresiones y llamadas a funciones.
*Ejemplo:* `math.exp(math.log(x+1))`
