Un dataframe es una estructura de datos tabular bidimensional donde cada columna es, en sí misma, una [[4.1 Series|serie]].
#### Inicialización 
Se pueden generar a partir de [[2.3 Diccionarios|diccionarios]], donde las claves representan las etiquetas de las columnas y los valores son las colecciones de datos asociadas como [[2.2 Listas|listas]] o [[4.1 Series|series]].

Desde un diccionario:
```python
df = pd.DataFrame({'Poblacion': poblacion_s, 'Superficie_km2': superficie_s})
```

El acceso se realiza seleccionando columnas enteras por etiqueta, o extrayendo subconjuntos de filas y columnas filtrando por posición numérica con `iloc` o por nombre con `loc`.

**Ejemplos:**
```python
# Acceso a una columna entera (devuelve una Serie)
columna = df['Poblacion']

# Acceso por posición (iloc): selecciona la fila 0 y la columna 1
valor = df.iloc[0, 1]

# Acceso por etiqueta (loc): selecciona varias filas y una columna por sus nombres
sub_df = df.loc[['Salta', 'Buenos Aires'], ['Poblacion']]

# Filtrado con máscara: seleccionar columnas específicas para las filas que cumplan una condición
filtrado = df.loc[df['Superficie_km2'] > 148008, ['Poblacion']]
```

#### Operaciones con DataFrames

| **Operación / Propiedad**   | **Operador / Atributo** | **Ejemplo**                     |
| --------------------------- | ----------------------- | ------------------------------- |
| Crear desde diccionario     | `pd.DataFrame()`        | `pd.DataFrame(diccionario)`     |
| Dimensión (filas, columnas) | `.shape`                | `df.shape`                      |
| Tipos de datos              | `.dtypes`               | `df.dtypes`                     |
| Etiquetas de columnas       | `.columns`              | `df.columns`                    |
| Acceso por etiqueta         | `.loc[ ]`               | `df.loc['fila', 'columna']`     |
| Acceso por posición         | `.iloc[ ]`              | `df.iloc[0, 1]`                 |
| Suma por eje                | `.sum()`                | `df.sum(axis=0)`                |
| Promedio por eje            | `.mean()`               | `df.mean(axis=0)`               |
| Aplicar función a elementos | `.apply()`              | `df['columna'].apply(funcion)`  |
| Longitud de cadena          | `.str.len()`            | `df['columna_texto'].str.len()` |
