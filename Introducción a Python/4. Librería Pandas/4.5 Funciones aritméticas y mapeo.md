[[4. Pandas|Pandas]] facilita la aplicación de cálculos estadísticos y transformaciones personalizadas sobre las estructuras de datos, minimizando la necesidad de iterar explícitamente.
#### Operaciones aritméticas básicas
Las operaciones se aplican de forma vectorizada sobre las columnas numéricas.
* **Suma de escalares:** `df['columna_A'] + 10`
* **Operaciones entre columnas:** `df['columna_A'] / df['columna_B']`

#### Funciones estadísticas
Al usar métodos de agregación directos en un DataFrame, el parámetro `axis` determina la dirección del cálculo:
* `axis=0` (Por defecto): Realiza el cálculo a lo largo de las filas (operación vertical, agrupando los valores de cada columna).
* `axis=1`: Realiza el cálculo a lo largo de las columnas (operación horizontal, procesando los datos fila por fila).

Ejemplos:
* **Sumatoria:** `df.sum(axis=0)` suma los valores numéricos de todas las filas para cada columna.
* **Promedio:** `df.mean(axis=0)` calcula la media aritmética.
* **Estandarización (z-score):** Las operaciones pueden encadenarse, por ejemplo: `(df - df.mean()) / df.std()`.

#### Transformación con `apply`
Para ejecutar transformaciones más complejas o condicionales que no están cubiertas por las operaciones matemáticas básicas, se utiliza el método `apply`. Permite ejecutar una función sobre cada fila o columna de un conjunto de datos.

Se puede utilizar con funciones predefinidas o con funciones anónimas `lambda`:
```python
# Usando una función lambda para dividir una cadena y contar los elementos
df['conteo_palabras'] = df['columna_texto'].apply(lambda x: len(x.split(' ')))

# Usando una función externa previamente definida
df['transformada'] = df['columna_numerica'].apply(mi_funcion_calculo)
```

### Operaciones aritméticas y mapeo

| Operación / Propiedad | Método / Operador | Ejemplo genérico |
| :--- | :--- | :--- |
| Operación entre columnas | Operadores matemáticos (`+`, `-`, `/`, `*`) | `df['col'] / df['col2']` |
| Operación con escalar | Operadores matemáticos (`+`, `-`, `/`, `*`) | `df['col'] + 10` |
| Sumatoria | `.sum()` | `df.sum(axis=0)` |
| Media aritmética | `.mean()` | `df.mean(axis=0)` |
| Desviación estándar | `.std()` | `df.std(axis=0)` |
| Aplicar función anónima | `.apply()` y `lambda` | `df['col'].apply(lambda x: len(x.split(' ')))` |
| Aplicar función definida | `.apply()` | `df['col'].apply(funcion_personalizada)` |
