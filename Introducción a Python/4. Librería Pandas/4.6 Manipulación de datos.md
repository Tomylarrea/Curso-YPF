#### Agregación y agrupamiento
Permiten calcular métricas estadísticas sobre todo el DataFrame o segmentado por categorías.
* **Agregación múltiple:** aplica una o varias funciones estadísticas a columnas específicas usando un diccionario.
  `df.agg({'columna_A': ['sum', 'min'], 'columna_B': 'max'})`
* **Agrupamiento:** segmenta los datos usando una o más columnas como clave, sobre las cuales luego se aplican funciones de agregación. Si se usa `as_index=False`, las columnas de agrupación no se transforman en el índice del nuevo DataFrame.
  `df.groupby(['columna_A', 'columna_B'], as_index=False).mean()`

#### Tablas dinámicas
Reorganizan los datos de una forma similar a las hojas de cálculo, cruzando variables en filas y columnas.
* **`pivot_table`:** cruza la información indicando qué columna formará el índice (`index`), cuál las columnas (`columns`), qué valores se van a calcular (`values`) y la función estadística a aplicar (`aggfunc`).
  `pd.pivot_table(df, values=['columna_valores'], index=['columna_filas'], columns=['columna_categorias'], aggfunc='count')`

#### Combinación de tablas
Para unificar información dispersa en distintos DataFrames, se usan métodos de apilamiento o cruces relacionales.
* **Concatenación:** une listas de DataFrames. Por defecto (`axis=0`) los apila verticalmente (agrega filas). Con `axis=1` los pega horizontalmente (agrega columnas).
  `pd.concat([df1, df2], axis=0)`
* **Fusión relacional:** cruza DataFrames usando una columna en común como clave (similar a los JOIN en SQL). El parámetro `how` define el tipo de cruce (`inner`, `outer`, `left`, `right`).
  `pd.merge(df1, df2, on='columna_clave', how='inner')`

### Operaciones de manipulación y combinación

| Operación / Propiedad         | Método / Función           | Ejemplo genérico                                                                  |
| :---------------------------- | :------------------------- | :-------------------------------------------------------------------------------- |
| Agregación múltiple           | `.agg()`                   | `df.agg({'col1': 'sum', 'col2': 'mean'})`                                         |
| Agrupar por categoría         | `.groupby()`               | `df.groupby('col_clave').sum()`                                                   |
| Agrupar sin afectar el índice | `.groupby(as_index=False)` | `df.groupby('col_clave', as_index=False).mean()`                                  |
| Crear tabla dinámica          | `pd.pivot_table()`         | `pd.pivot_table(df, values='val', index='fila', columns='col')`                   |
| Apilar DataFrames             | `pd.concat()`              | `pd.concat([df1, df2], axis=0)` filas<br>`pd.concat([df1, df2], axis=1)` columnas |
| Fusión interna o externa      | `pd.merge()`               | `pd.merge(df1, df2, on='clave', how='inner/outer')`                               |
