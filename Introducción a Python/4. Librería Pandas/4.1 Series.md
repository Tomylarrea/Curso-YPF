Una serie es una estructura unidimensional formada a partir de una lista de datos. Cuando no se especifica un índice, se crea uno predeterminado con números enteros del $0$ al $N-1$.
#### Inicialización
Se pueden generar a partir de listas o diccionarios.

* **Desde una lista**:
  `s = pd.Series([4, 17, -51, 3], name='Serie A')`
* **Desde una lista con índice especificado:**
  `s = pd.Series([4, 17, -51, 3], name='Serie A', index=['d', 'b', 'a', 'c'])`
* **Desde un diccionario:** las claves asumen el lugar del índice.
  `superficie_s = pd.Series({'Buenos Aires': 305907.4, 'Córdoba': 164707.8})`

Al pasar explícitamente una lista al parámetro `index`, Pandas prioriza estrictamente esas etiquetas. Si una etiqueta de la lista no existe como clave en el diccionario original la incluye en el índice pero le asigna un valor nulo (`NaN`) al no tener dato asociado. Por ejemplo:
```python
superficie_dict = {'Buenos Aires': 305907.4, 'Córdoba': 164707.8}
superficie_s2 = pd.Series(superficie_dict, index=['Buenos Aires', 'Córdoba', 'Misiones'])
```
Devuelve
```Consola
Buenos Aires    305907.4
Córdoba         164707.8
Misiones             NaN
dtype: float64
```
#### Indexación

El acceso a los elementos se realiza utilizando las etiquetas del índice, ya sea para extraer un valor específico, un subconjunto mediante una lista de etiquetas, o filtrando con máscaras booleanas.

**Ejemplos:**
```python
# Acceso directo a un elemento mediante su etiqueta
valor = s['a'] 

# Acceso múltiple: seleccionar varios elementos pasando una lista de etiquetas
sub_serie = s[['c', 'a', 'd']] 

# Filtrado con máscara: seleccionar solo los elementos mayores o iguales a 0
valores_positivos = s[s >= 0] 
```
### Operaciones con series

| **Operación / Propiedad**  | **Operador / Atributo**       | **Ejemplo genérico**            |
| -------------------------- | ----------------------------- | ------------------------------- |
| Crear desde lista          | `pd.Series()`                 | `pd.Series([4, 17, -51, 3])`    |
| Crear desde diccionario    | `pd.Series()`                 | `pd.Series(diccionario)`        |
| Colección de valores       | `.values`                     | `serie.values`                  |
| Colección de etiquetas     | `.index`                      | `serie.index`                   |
| Multiplicación por escalar | `*`                           | `serie * 2`                     |
| Suma total                 | `.sum()`                      | `serie.sum()`                   |
| Valor máximo               | `.max()`                      | `serie.max()`                   |
| Evaluar nulos              | `pd.isnull()` / `.isnull()`   | `pd.isnull(serie)`              |
| Evaluar no nulos           | `pd.notnull()` / `.notnull()` | `pd.notnull(serie)`             |
| Longitud de cadena         | `.str.len()`                  | `df['columna_texto'].str.len()` |
