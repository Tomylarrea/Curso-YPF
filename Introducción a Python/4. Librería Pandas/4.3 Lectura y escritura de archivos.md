[[4. Pandas|Pandas]] proporciona métodos integrados para importar datos tabulares desde distintas fuentes y exportarlos una vez procesados.
#### Importación de datos
Para cargar conjuntos de datos en un entorno de trabajo, se utilizan las funciones de la familia `read_*`.
- **Archivos CSV:** los valores separados por comas son el formato más estándar. Por defecto, el separador asumido es la coma (`,`), pero puede modificarse con el parámetro `sep`.
    
    `df_csv = pd.read_csv("ruta_al_archivo.csv", sep=',')`
    
- **Archivos Excel:** para leer planillas `.xls` o `.xlsx`. Permite especificar parámetros como el número de fila donde empiezan los encabezados `header` o la hoja específica a leer `sheet_name`.
    
    `df_excel = pd.read_excel("ruta_al_archivo.xlsx", header=2)`
    
#### Exportación de datos
Una vez manipulados los datos, se pueden guardar utilizando las funciones de la familia `to_*`.

- **Exportar a CSV:** guarda el [[4.2 DataFrames|dataframe]] en el sistema local. Suele ser conveniente usar `index=False` para evitar que [[4. Pandas|Pandas]] escriba la columna de índices como un dato más.
    
    `df.to_csv("datos_procesados.csv", index=False)`
    
- **Exportar a Excel:** genera un archivo `.xls` o `.xlsx`.
    
    `df.to_excel("datos_procesados.xlsx", index=False)`
    

### Operaciones con archivos

| **Operación**      | **Función**       | **Ejemplo**                                |
| ------------------ | ----------------- | ------------------------------------------ |
| Leer archivo CSV   | `pd.read_csv()`   | `pd.read_csv("archivo.csv")`               |
| Leer archivo Excel | `pd.read_excel()` | `pd.read_excel("archivo.xlsx")`            |
| Exportar a CSV     | `.to_csv()`       | `df.to_csv("archivo.csv", index=False)`    |
| Exportar a Excel   | `.to_excel()`     | `df.to_excel("archivo.xlsx", index=False)` |
