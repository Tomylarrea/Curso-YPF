Pandas integra la librería Matplotlib para generar visualizaciones rápidas directamente desde [[4.1 Series|series]] y [[4.2 DataFrames|dataframes]]. De manera predeterminada, grafica un diagrama de líneas para cada columna numérica.
#### Tipos de gráficos
El método general es `.plot()`. El parámetro `kind` permite definir la estructura visual adecuada según los datos a explorar.
* **Líneas (`line`):** traza la evolución de valores numéricos.
* **Histogramas (`hist`):** permite ver la distribución de una variable numérica. Se ajusta la resolución con el parámetro `bins`.
  `df['col_num'].plot(kind='hist', bins=50)`
* **Dispersión (`scatter`):** explora la relación entre dos variables numéricas. Solo se aplica en [[4.2 DataFrames|dataframes]] y exige declarar los ejes X e Y.
  `df.plot(kind='scatter', x='col1', y='col2')`
* **Cajas (`box`):** genera diagramas de caja para analizar estadística descriptiva y valores atípicos.
* **Barras (`bar`):** ideal para variables categóricas. Se suele aplicar sobre una Serie previamente sumarizada con las frecuencias absolutas o relativas.
  `df['col_cat'].value_counts().plot(kind='bar')`

#### Integración con ``Matplotlib``
Todo gráfico generado desde [[4. Pandas|Pandas]] es un objeto de ``Matplotlib``. Se puede volcar la visualización en un lienzo configurado previamente pasándole el objeto al parámetro `ax`, facilitando la personalización de ejes, títulos y rotación.
### Operaciones para gráficos

| Operación / Propiedad       | **Parámetro**    | **Ejemplo**                                   |
| :-------------------------- | :--------------- | :-------------------------------------------- |
| Gráfico de líneas (Defecto) | `.plot()`        | `df.plot()`                                   |
| Histograma                  | `kind='hist'`    | `df['col_num'].plot(kind='hist', bins=20)`    |
| Gráfico de dispersión       | `kind='scatter'` | `df.plot(kind='scatter', x='col1', y='col2')` |
| Diagrama de caja            | `kind='box'`     | `df.plot(kind='box')`                         |
| Gráfico de barras           | `kind='bar'`     | `serie.plot(kind='bar')`                      |
| Definir ejes Matplotlib     | `ax=`            | `serie.plot(kind='bar', ax=ax)`               |
