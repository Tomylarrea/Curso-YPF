Los arreglos multidimensionales de NumPy son la estructura central para la computación científica en Python. A diferencia de las [[2.2 Listas|listas]] nativas, los `ndarray` almacenan elementos de un único tipo de dato, lo que permite un procesamiento vectorizado mucho más eficiente en términos de velocidad y consumo de memoria.
#### Inicialización
Se pueden inicializar a partir de estructuras existentes como [[2.2 Listas|listas]] o mediante funciones generadoras propias de NumPy.

**Ejemplos:**
```python
import numpy as np

# Desde una lista (1D)
arreglo = np.array([1, 2, 3, 4, 5])

# Arreglo bidimensional (Matriz 2D)
matriz = np.array([
    [1, 2, 3],
    [4, 5, 6]
])

# Arreglos comunes
ceros = np.zeros((3, 3))       # Matriz de 3x3 llena de ceros
rango = np.arange(0, 10, 2)    # Secuencia [0, 2, 4, 6, 8]
```

#### Operaciones con vectores
NumPy permite aplicar operaciones matemáticas directamente sobre el arreglo completo, sin necesidad de iterar con bucles `for`.

**Ejemplos:**
```python
a = np.array([1, 2, 3])
b = np.array([4, 5, 6])

# Operaciones elemento a elemento
suma = a + b       # Devuelve [5, 7, 9]
multi = a * b      # Devuelve [4, 10, 18]

# Operaciones con escalares
escalar = a * 10   # Devuelve [10, 20, 30]
```

#### Indexación
El acceso a los elementos es similar al de las [[2.2 Listas|listas]], pero adaptado para múltiples dimensiones, separando los índices por comas.

**Ejemplos:**
```python
# Acceso directo en 2D (Fila 0, Columna 1)
valor = matriz[0, 1] 

# Seleccionar todas las filas (:), pero solo la columna 2
columna = arr_empresas[:, 2] 

# Seleccionar desde la fila 1 en adelante, y las columnas 2 y 3
submatriz = arr_empresas[1:, [2, 3]]
```

### Operaciones con arreglos

| **Operación / Propiedad**          | **Operador  / Función** | Ejemplo en el documento                     |
| :--------------------------------- | :---------------------- | :------------------------------------------ |
| Crear desde [[2.2 Listas\|listas]] | `np.array()`            | `np.array([1, 2, 3])`                       |
| Arreglo de ceros                   | `np.zeros()`            | `np.zeros((3, 3))`                          |
| Arreglo de unos                    | `np.ones()`             | `np.ones((2, 4))`                           |
| Secuencia numérica                 | `np.arange()`           | `np.arange(0, 10, 2)`                       |
| Espaciado uniforme                 | `np.linspace()`         | `np.linspace(0, 1, 5)`                      |
| Cantidad de dimensiones / ejes     | `.ndim`                 | `matriz.ndim`                               |
| Forma                              | `.shape`                | `matriz.shape` devuelve `(filas, columnas)` |
| Cantidad total de elementos        | `.size`                 | `matriz.size`                               |
| Suma elemento a elemento           | `+`                     | `a + b`                                     |
| Multiplicación elemento a elemento | `*`                     | `a * b`                                     |
| Suma de todos los elementos        | `.sum()`                | `datos.sum()`                               |
| Promedio de los elementos          | `.mean()`               | `datos.mean()`                              |
| Valor máximo entre los elementos   | `.max()`                | `datos.max()`                               |
