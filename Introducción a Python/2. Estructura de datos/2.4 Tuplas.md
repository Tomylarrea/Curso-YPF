Son secuencias de valores ordenados al igual que las [[2.2 Listas|listas]], pero no se pueden modificar sus elementos una vez definida. Son útiles cuando es necesario asegurar que la información no se modifique accidentalmente. Al tener un tamaño fijo, se les asigna la memoria justa de entrada y no desperdicia recursos calculando expansiones futuras. También presentan mejoras en la optimización en tiempos de compilación.

**Ejemplo:**
```python
tupla = (3, 'Auto', 8.9)
# tupla[0] = 24 generaría un error.
```
### Operaciones con tuplas

| Operación  | Operador / Función | Ejemplo                                       |
| :--------- | :----------------: | :-------------------------------------------- |
| Conversión |     `tuple()`      | `tuple('Python')`                             |
| Indexación |       `[ ]`        | `tupla[0]`<br>`tupla[-3]`<br>`tupla[1:3]`<br> |
