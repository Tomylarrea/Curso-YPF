Otro tipo incorporado en este lenguaje son los de tipo `set`, que representan un conjunto matemático: una colección de elementos en la que **cada elemento se identifica únicamente por su pertenencia al conjunto**, sin un orden determinado. Por esta razón, un elemento puede pertenecer o no al conjunto, pero no tiene sentido que pertenezca más de una vez.

Los elementos de un conjunto deben ser _hashable_. Esto significa que Python puede asociarles un **valor _hash_**, un número entero calculado a partir del objeto que permanece constante durante su vida útil. Este valor permite determinar eficientemente si un elemento pertenece al conjunto. Por ejemplo, los enteros y las cadenas son _hashable_, mientras que las [[2.2 Listas|listas]] no lo son porque pueden modificarse.

Para crear un conjunto, por ejemplo:

```python
conjunto = {2,4,'hola','hola'}
print(conjunto)
```
Devuelve:
```Consola
{'hola', 2, 4}
```

Los conjuntos también se pueden definir como:
```python
set((2,4,'hola','hola'))
```

### Operaciones con conjuntos

| Operación        | Método / Operador      | Ejemplos                    |
| :--------------- | :--------------------- | :-------------------------- |
| Agregar elemento | `.add()`               | `A.add(10)`                 |
| Unión            | `.union()`             | `A.union(B)`                |
| Intersección     | `.intersection()`      | `A.intersection(B)`         |
| Diferencia       | `.difference()` o `-`  | `A.difference(B)` o `A - B` |
 El operador `-` exige que ambos lados de la expresión sean estrictamente conjuntos. En cambio, el método `.difference()` acepta cualquier iterable como una [[2.2 Listas|lista]], una [[2.4 Tuplas|tupla]] o un [[2.1 Strings|string]] como argumento y lo convierte conjunto.
