Son secuencias ordenadas de elementos de cualquier tipo. Su principal característica es que son mutables, por lo que es posible alterar su contenido agregando, editando o eliminando ítems. El índice del primer elemento es el cero. 

**Ejemplo:**
```python
lista = [1, 42, 3j, 'Hello']
lista[0] = "Python" # Ahora la lista es ["Python", 42, 3j, 'Hello']
```

### Operaciones con listas

| Operación        | Método / Operador | **Ejemplo**                                |
| :--------------- | :---------------- | :----------------------------------------- |
| Indexación       | `[ ]`             | `lista[0]` <br>`lista[-3]`<br>`lista[1:3]` |
| Pertenencia      | `in` / `not in`   | `3 in a` <br>`8 not in a`                  |
| Agregar elemento | `.append()`       | `lista.append(10)`                         |
