
Las cadenas de texto representan información en formato de texto y se definen encerrando los caracteres entre comillas. En Python, no existe un tipo de dato específico para caracteres individuales tales como `char`; una sola letra es simplemente una cadena de longitud uno.
#### Acceso e indexación
Los elementos de una cadena se pueden acceder individualmente usando corchetes. El índice siempre arranca desde `0`.

**Ejemplo:**
```python
palabra = 'Python'
palabra[0] # devuelve 'P'
palabra[5] # devuelve 'n'
```

#### Inmutabilidad
Las cadenas son estrictamente inmutables. Una vez definidas, no se puede alterar su contenido reemplazando caracteres en índices específicos.

**Ejemplo:**
```python
palabra[0] = 'p' # No está permitido
```

#### Operaciones con cadenas

| Operación                                     | Operador / Función | **Ejemplo**                                         |
| :-------------------------------------------- | :----------------- | :-------------------------------------------------- |
| Concatenación                                 | `+`                | `'mar' + 'playa'` devuelve `marplaya`               |
| Repetición                                    | `*`                | `'Spam'*3` devuelve `SpamSpamSpam`                  |
| Longitud                                      | `len()`            | `len(palabra)` devuelve la cantidad de caracteres   |
| Verificar si toda la cadena está en mayúscula | `.isupper()`       | `c.isupper()` devuelve `True` o `False`             |
| Separar en [[2.2 Listas\|listas]]             | `.split()`         | `texto1.split(' ')` devuelve las palabras del texto |
