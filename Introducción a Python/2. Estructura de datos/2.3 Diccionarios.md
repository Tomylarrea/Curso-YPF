Un diccionario contiene una colección de índices, llamados claves, y una colección de valores. Cada clave está asociada a un único valor. Esta asociación se denomina **par clave-valor**, o simplemente **ítem**. En términos matemáticos, un diccionario representa un mapeo entre claves y valores; por lo tanto, se puede decir que cada clave «mapea a» un valor.

**Ejemplo:**
```python
diccionario = {'m': 0, 'a': 'Felipe', 'd': 5}
diccionario['a'] = 10 # Se actualiza el valor asociado a la clave 'a'
```

También se puede definir un diccionario utilizando `dict()`:
```python
dict ((('m',0),('a',2), ('d', 5)))
```
 o, alternativamente
```python
diccionario = dict()
diccionario['m']= 0
diccionario['a']= 2
diccionario['d']= 5
```

### Operaciones con diccionarios

| Operación                        | Operador / Función | Ejemplo                             |
| :------------------------------- | :----------------- | :---------------------------------- |
| Pertenencia (solo evalúa claves) | `in`               | `'r' in diccionario`                |
| Obtener pares clave-valor        | `.items()`         | `diccionario.items()`               |
